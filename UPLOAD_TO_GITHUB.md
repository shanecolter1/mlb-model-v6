# Upload this repository to GitHub

1. Extract `mlb-model-v6-git-ready.zip`.
2. Open the extracted `mlb-model-v6` folder.
3. Select everything inside that folder.
4. Drag the selected contents into the empty GitHub repository.
5. Commit the upload.

Do not upload the outer `mlb-model-v6` folder as one item.

After upload, the repository root should show `.github`, `config`, `docs`,
`src`, `tests`, `README.md`, `package.json`, and `requirements.txt`.

The workflow must be located at:

`.github/workflows/historical_research.yml`
